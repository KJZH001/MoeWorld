# 抽签
这里会讲述抽签的相关内容

抽签同时受到星空酱和琉璃酱的支持，但是她们两姐妹的抽签能力存在有一定的差别

抽签虽然被命名为`每日抽签`，但是实际上没有做出限制，只要你乐意可以随便抽取，这也是我所希望的

抽签是为了开心，而不是让自己难受一整天

## 种类和概率分布
每种抽签都是采用奖池机制，来控制抽签的分布概率，但是每次的奖池都会被还原到默认的状态再为下一个人抽取

所以虽然说是奖池，但是概率是恒定的

抽签的逻辑为，从奖池中随机抽取一个类别，每个类别的单个概率平均，但是类别会被重复，以此来控制概率

吉签的整个类别的概率是最大的，甚至经过多次的翻倍增多，最后才确定在现在的概率

获取到类别后，才会在此类别中随机抽取一枚实际的签

### 普通签
最普通的抽签，拥有完整的奖池

```
"大吉","大吉","大吉","中吉","吉","吉","小吉","小吉","末吉","凶","大凶","彩蛋"
```
### 吉签
此类别中不会有凶签和彩蛋的存在，甚至连末吉都没有

对应的其实是显示中，日本的新年参拜的原则，新年参拜中最小也一定是小吉

```
"大吉","大吉","大吉","中吉","吉","吉","小吉","小吉"
```

### 恋签
其实是之前从樱云之恋那套图片里爬取了几张随便做的

后面因为图全也懒得修bug，干脆就去掉了（其实api的资源接口还保留着，但是私有当然接口是不可能公开的啦w）

```
"大吉","中吉","小吉","半吉","吉","小凶","彩蛋"
```

## 来抽签吧！

### 普通抽签
普通抽签你只需要在群内发送`抽签`即可，星空酱会为你抽取一个签，签的内容是随机的

或者你也可以发送`@琉璃酱 /抽签`来让琉璃酱帮你抽签一枚签

她们二者抽取的签的内容和概率是相同的，**但是琉璃酱只能抽取普通的签**

### 吉签
吉签是一种特殊的抽签，她只会抽取到吉签，不会有凶签和彩蛋的存在

你可以发送`吉签`来让星空酱为你抽取一个吉签
